## Описание продукта

Необходимо разработать backend для AI-платформы поиска работы.

### Основной функционал

- Регистрация и авторизация пользователей.
- Загрузка PDF-резюме.
- AI-парсинг резюме в структурированный JSON.
- Определение должности, грейда, опыта, навыков.
- Возможность ручного редактирования всех данных.
- Генерация сопроводительных писем.
- AI Match Score для вакансий.
- Парсинг вакансий (HeadHunter, Хабр Карьера, GetMatch, карьерные
  сайты компаний через Playwright).
- Гибкая система фильтров.
- Избранное, история откликов, рекомендации вакансий.

## Анализ резюме

Нужно извлекать из pdf : - Position - Grade (Intern / Junior / Middle /
Senior / Lead) - Experience - Skills - Education - English - Projects -
Work Experience - Summary

Все данные сохраняются отдельно и могут редактироваться пользователем.

## AI Match

Для каждой вакансии рассчитывать: - процент соответствия; - сильные
стороны; - слабые стороны; - отсутствующие навыки.

## Генерация сопроводительных писем

На основе: - резюме; - профиля пользователя; - описания вакансии.

Возвращать несколько вариантов письма.

## Парсинг вакансий

Источники: - HeadHunter - Хабр Карьера - GetMatch - LinkedIn (если
доступно) - карьерные сайты компаний (Playwright)

## Фильтры

- страна
- регион
- город
- удалённая работа
- офис
- гибрид
- зарплата (от/до)
- стек технологий
- грейд
- компания
- тип занятости
- английский язык
- дата публикации
- только вакансии с зарплатой

## Архитектура

Использовать: - Clean Architecture - DDD - Dependency Injection -
Repository Pattern
